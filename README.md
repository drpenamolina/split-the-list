# Split the list

Split a team census between residents and print rounds cards.

**Open it:** https://drpenamolina.github.io/split-the-list/

Everything runs in your browser. The census PDF, Meditech PDFs and AI summaries are read on
your computer and are never uploaded; nothing is sent to a server. Resident names and the
last split (coded, no patient names) are remembered only in your own browser.

`index.html` is generated by `build.py` from the main project's sources. Don't edit it by hand.
